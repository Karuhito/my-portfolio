# ポートフォリオサイト改修 設計書

作成日: 2026-11-09
対象: `my-portfolio`（React 19 + Vite 8、JSX、シングルページ）

## 1. 背景と目的

現行サイトは装飾が派手で、本人と友人から次の2点を指摘された。

- 「AI で作った感じ」が強い
- バックエンドエンジニアなのに「フロントをバリバリやる人」に見える

改修の目的は、見た人に **「真面目なバックエンドエンジニア」** という印象を持ってもらうこと。装飾ではなく、余白、文字サイズの差、情報の順番で整った印象を出す。

## 2. 目標 / 非目標 / アンチゴール

### 目標
- 派手な装飾をすべて取り除き、落ち着いた見た目にする
- ライト / ダークを切り替えられるようにする
- 絵文字アイコンを Lucide アイコンに置き換える
- 制作物に画像サムネイルを載せられるようにする
- バックエンドが主軸だと伝わる情報の並びにする

### 非目標
- セクション構成や配置の変更（現状のまま）
- 複数ページ化、ルーティング、CMS の導入
- 自己紹介・制作物説明などの **文章の書き換え**（本人が後で行う。実装では既存の文章をそのまま残す）
- TypeScript への移行（既存プロジェクトは JSX のため、JSX のまま進める：**私の判断**）

### アンチゴール（技術的に動いても失敗とみなすもの）
- フェードイン、ホバー時の大きな変化、グロー、追従カーソルなど「動き」や「光り」が残っている
- ネオン系の色、グラデーション、グリッド背景が残っている
- 技術スタックで、フロントエンドがバックエンドより目立っている
- ダークモードで、読み込み時に一瞬白く光る（ちらつく）

## 3. 本人が決めたこと

- 配置は現状のままにする。順序は Nav → Hero → About（文章 + 写真の2カラム）→ Skills（カードのグリッド）→ Projects（行リスト）→ Experience（タイムライン）→ Contact → Footer
- 絵文字のアイコンを Lucide アイコンにする
- ダーク / ライトモードを切り替えられるようにする
- フェードインなどのモーションはつけない
- 制作物の各行にサムネイル画像を載せる。4件分の画像は本人が用意する
- 自己紹介と制作物の説明文は本人が書き直す

## 4. デザイン仕様

モックアップは `.superpowers/brainstorm/39715-1794208391/content/current-layout-calm.html` と `projects-thumbnail.html` にある。見た目（色・余白・配置）の基準はこの2枚とする。**文言はモックアップではなく現行の `content.js` と各コンポーネントの文字列に従う**（モックアップの文言は仮置き）。セクション見出し（「職歴・学歴」など）、Hero の肩書き、Contact の見出しは現行のまま残す。

### 4.1 色（CSS 変数）

ライト（`:root`）とダーク（`[data-theme="dark"]`）で、同じ変数名の値を差し替える。

| 変数 | ライト | ダーク | 用途 |
|---|---|---|---|
| `--bg` | `#ffffff` | `#0d1117` | 背景 |
| `--bg-soft` | `#f6f8fa` | `#151b23` | ボタン、写真枠、サムネイル枠の背景 |
| `--text` | `#1f2328` | `#e6edf3` | 本文 |
| `--text-sub` | `#59636e` | `#9198a1` | 補足、日付、タグ |
| `--border` | `#d8dee4` | `#30363d` | 区切り線、枠線 |
| `--link` | `#0969da` | `#4493f8` | リンク色（アクセントはこの1色だけ） |

これ以外の色は使わない（`#000` / `#fff` 系の微調整は可）。

### 4.2 文字
- フォントは Google Fonts を使い続ける。**使うフォントは本人が選ぶ**（本人の決定）
  - 実装では、フォントを `global.css` の CSS 変数 `--font-body`（本文）と `--font-heading`（名前・見出し）の2つに集約する。Google Fonts の `@import` も1か所にまとめ、本人がこの2か所を書き換えるだけで差し替えられるようにする
  - 各 CSS ファイルに直接書かれている `font-family` の指定は、すべてこの変数の参照に置き換える
  - 初期値は現行のまま（本文 = JetBrains Mono、見出し = Syne）にする
- 本文 15px / 行間 1.8、セクション見出し 20〜22px / 太字、名前（Hero の h1）32〜40px / 太字
- 大文字変換（`text-transform: uppercase`）、広い字間、マイナス字間はやめる
- セクション見出しは日本語のみにする（`// 01 about` のようなラベルは削除）

### 4.3 レイアウト共通
- コンテンツの最大幅は 880px で中央寄せ、左右の余白は 32px（スマホは 20px）
- セクション同士は上下 56〜72px の余白と、1px の区切り線で分ける
- 角丸は 6px で統一。タグだけ pill 形（`999px`）にする
- 影（`box-shadow`）は使わない

### 4.4 動き
- `transition` / `animation` / `@keyframes` は使わない。ホバー時は色だけが変わる（transition なし）
- スムーズスクロールは残してよい（ナビのクリック時のみ。`prefers-reduced-motion: reduce` のときは即時ジャンプ）（**私の判断**）

### 4.5 アイコン
- `lucide-react` を依存に追加する。サイズは 16px、`strokeWidth` は 2
- Skills のアイコン: バックエンド = `Server`、データベース = `Database`、フロントエンド = `Code`（**私の判断**）
- テーマ切り替えボタン: ライト表示中は `Moon`、ダーク表示中は `Sun`
- 制作物のリンク: `ArrowUpRight`、メール: `Mail`、サムネイル未設定時: `ImageOff`
- Lucide にはブランドロゴ（GitHub / Wantedly）がないため、この2つは既存の SVG パスを流用する。色は `currentColor` にする

## 5. セクション別の仕様

### Nav
- 上部固定のまま。背景は `--bg`（半透明やぼかしはやめる）、下に1px の線
- 左に `Enomoto Kazuto`（太字・通常サイズ）、右に日本語のリンク（自己紹介 / 技術 / 制作物 / 経歴 / 連絡先）とテーマ切り替えボタン
- スマホではリンクを隠し、名前とテーマボタンだけを表示する（現行の挙動に合わせる）

### Hero
- 削除するもの: グリッド背景、グロー、`▸ Engineer` タグ、右下の数値（`profile.stats`）、`min-height: 100vh`
- 残すもの: 名前（漢字の「榎本 和斗」を h1 に、英字は補足として小さく）、一行の肩書き、ボタン2つ（「制作物を見る」= 塗り、「連絡する」= 枠線）
- `content.js` の `profile.stats` は使わなくなるので削除する

### About
- 2カラム（文章 / 写真）の配置は維持する
- ターミナル風の `profile.json` 表示を削除し、代わりに定義リスト（`dl`）で 所在地 / 主な言語 / 学習中 を表示する。値は `profile.location` / `profile.languages` / `profile.interests` から出す
- 写真は円形、グロー、リングをやめ、角丸 8px の四角（220px 前後）に 1px の枠線をつける。画像読み込み失敗時のプレースホルダーは `ImageOff` アイコンにする

### Skills
- カードのグリッド配置は維持する
- `content.js` の `skills[].icon` を絵文字から Lucide のアイコン名（文字列）に変え、コンポーネント側で対応表から描画する
- 並び順は バックエンド → データベース → フロントエンド（現在はフロントが先頭）。配列の順番だけを入れ替える
- **タグの中身（`skills[].tags`）と `profile.interests` の値は変更しない**。本人が文章と一緒に後で直す（本人の決定）。そのため、アンチゴール「フロントエンドがバックエンドより目立つ」のうちタグ数の偏りは、本人のデータ修正で解消する前提とする
- `content.js` 内のコメントアウトされたブロック（インフラ・セキュリティ）は、CLAUDE.md の規約に従い削除する

### Projects
- 行リストの配置は維持する。各行を `サムネイル(200px) | タイトル・説明・タグ | リンク` の3カラムにする
- 現行の連番（`01` など）は削除する
- `projects[].thumbnail`（例: `"/projects/journalog.png"`）を読めるようにする。画像は `public/projects/` に置く。実装時点では画像がないため、`thumbnail` は **未設定のまま** にし、プレースホルダーが出る状態で完成とする。画像が届いたら本人がパスを追記する（**私の判断**）
- サムネイル枠は `aspect-ratio: 16 / 10`、`object-fit: cover`、1px 枠線、角丸 6px。`thumbnail` が未設定か読み込みに失敗した場合は `ImageOff` アイコンのプレースホルダーを出す
- `<img>` には `alt`（制作物タイトル）、`loading="lazy"` をつける
- リンクには `rel="noreferrer"` をつける（現状はついていない）
- スマホではサムネイルを上、文章を下に縦積みにする

### Experience
- タイムラインの配置は維持する。左に日付（`--text-sub`）、右に `title`（太字）、所属（`--text-sub`）、説明の順で表示する。`title` は削除しない（文言は本人が後で直す）

### Contact
- 見出しと一文はそのまま残す（本人が後で書き換える）
- リンクは枠線ボタン3つ（Email / GitHub / Wantedly）。大文字表記をやめる

### Footer
- `© 2026 Enomoto Kazuto` の1行だけにする。`Built with React` と英字のサブ行は削除する

### App 全体
- カスタムカーソル（`cursorRef` / `trailRef` と、それに対応する CSS）と `cursor: none` を削除する
- フェードイン用の `IntersectionObserver` と `.fade-in` クラスを削除する

## 6. テーマ切り替えの仕様

- テーマは `<html>` 要素の `data-theme` 属性（`light` / `dark`）で管理する
- 初期値（**私の判断**）: `localStorage` の `theme` に保存値があればそれを使い、なければ OS 設定（`prefers-color-scheme`）に合わせる
- ちらつき防止のため、`index.html` の `<head>` に小さなインラインスクリプトを置き、React の描画前に `data-theme` を設定する
- ボタンを押すと切り替わり、`localStorage` に保存する。`localStorage` が使えない環境でも例外を出さないよう `try/catch` で囲む
- ボタンには `aria-label`（「ダークモードに切り替え」など）をつける
- `color-scheme` プロパティもテーマに合わせて設定する（スクロールバーやフォーム部品の色合わせのため）
